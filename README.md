# Omar Walid — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Customize before publishing
- Replace `OMAR WALID`, biography and education details in `index.html`.
- Replace the placeholder email and `href="#"` social links with your real links.
- Replace demo project cards and descriptions with your real projects.
- Replace the decorative portrait placeholder in the hero with your own image if desired.
- Edit colors in `:root` at the top of `style.css` (`--blue` and `--blue2`).
